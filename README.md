# 强化助手

为《银河奶牛放置》（Milky Way Idle）提供强化路线、期望消耗、工时费和利润估算，汇总材料、库存缺口与备料计划。安装后刷新游戏，在侧栏打开「强化助手」。支持中文与英文。

[从 Greasy Fork 安装](https://greasyfork.org/zh-CN/scripts/599358)

## 主要功能

- **强化方案比较**：比较路线、期望时间、次数、消耗和收益，结合所选参考售价与官方行情辅助规划。
- **材料与备料计划**：汇总材料需求、已有库存、采购缺口和预算，可选择采购或自制底子，使用独立备料车整理清单。
- **市场与项目管理**：查看已获取的买卖挂单、本人订单和已观察到的成交记录，保存收藏、分区及参考售价。
- **导航与预填**：定位游戏市场、制作或强化页面并预填参数，最终购买、出售、制作和强化由玩家点击确认。
- **经验与本地备份**：预估强化及制造经验，支持设置、分区和计划的本地备份。

期望消耗、工时费和利润是估算，不保证实际收益或成交价格。没有逐笔价格与时间的数据不会显示为真实成交记录。插件不会自动购买、出售、制作或强化，不读取登录凭据，不上传游戏数据。计划、设置与已保存记录留在本地。

## 安装与活跃统计及隐私

强化助手的安装与活跃统计默认关闭，可在游戏内「强化助手 → 设置与备份 → 安装与活跃统计」阅读说明并确认开启，也可随时关闭，不影响插件功能。

- 开启时仅向柆雨的统计服务发送插件标识、版本和随机安装标识的 SHA-256 摘要，用于统计安装数与每日活跃安装数，不统计游戏内操作。
- 不使用硬件指纹，不发送账号、角色、聊天、资产、交易或 Cookie。安装标识仅保存在该脚本的 Tampermonkey 存储中；摘要用于识别同一安装。请求通过 HTTPS 发送。
- 关闭后不再上报，已有历史保留。

完整说明与源码见 [GitHub 项目](https://github.com/LaYuDr/mwi-layu-enhancement)。
