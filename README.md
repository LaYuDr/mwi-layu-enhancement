# 强化助手

为《银河奶牛放置》（Milky Way Idle）提供强化路线、期望消耗、工时费和利润估算，汇总材料、库存缺口与备料计划。安装后刷新游戏，在侧栏打开「强化助手」。支持中文与英文。

[从 Greasy Fork 安装](https://greasyfork.org/zh-CN/scripts/599358)

## v0.3.26 本次更新

- 市场“左一预估”优先沿用同表挂单的工时费计算与显示，保留保护等级标记；售价统一为金额在前、金币图标在后。
- 挂单自动收藏仅接收装备（含 +0）；启动时清理已确认的非装备收藏，先保存清理快照并纳入设置备份，分类未知时延后处理。
- 原生配装中的自用装备不再自动计入生产备料、续强化底子或目标抵扣；同件跨配装去重，多余副本仍可用，并兼容最高强化等级选项。

## 主要功能

- **版本与自动更新**：打开插件时检查公开版本，面板提示可用更新；可在「设置与备份 → 版本与自动更新」手动重查并打开安装入口。安装由 Tampermonkey 确认，更新后刷新游戏生效，后台自动更新频率由 Tampermonkey 设置决定。
- **强化方案比较**：比较路线、期望时间、次数、消耗和收益，结合所选参考售价与官方行情辅助规划。
- **装备对比与日期规划**：在「装备对比 → 日期规划」中设置起止时间、预算、周转金、每周代币和金币/经验权重，比较装备、天文台及神龛升级的期望收益；神龛需同角色公会助手提供只读报价。支持查看步骤、保存和导出方案，有限搜索不保证全局最优，现金按预期回款估算。
- **材料与备料计划**：汇总材料需求、已有库存、采购缺口和预算，可选择采购或自制底子，使用独立备料车整理清单。
- **独立强化计划**：自动同步游戏中的强化队列，队列外计划可从列表加入并调整顺序；汇总强化耗材和保护材料，按计划顺序分配当前金币，显示总期望时长、逐行近似成功率及库存材料可支撑时间。支持队列外计划清空撤销、库存与待到账抵扣以及购买预填。
- **常备数量与已有装备**：在主列表设置常备数量，数量不足时推荐补充到强化计划，由玩家确认添加；已有装备按强化等级显示原生风格图标，悬停查看库存及挂单明细，兼容强化等级配色插件。
- **全屏模式（开发中）**：默认关闭，从「设置 → 全屏模式（开发中）→ 进入全屏」手动进入，刷新后回到普通模式。左侧为主列表，右侧为强化计划与材料账本，两层分隔均可调整并保存；原生市场、制造与强化窗口保留在全屏上层，操作仍需玩家确认。
- **市场与项目管理**：查看已获取的买卖挂单、本人订单和已观察到的成交记录，保存收藏、分区及参考售价。
- **参考售价回退与计划资金**：可设置无行情时使用参考售价；强化计划按当前库存和金币分配展示材料与资金缺口，保留未知与零值的区别。
- **大收藏列表**：大量收藏按可见区域挂载，搜索和排序仍覆盖全部项目；保留已展开详情及正在编辑的输入，减少重复计算与刷新。
- **收集与价格预估**：收藏装备出售后，可收集收益并按已售数量补充计划，支持批量操作；市场卖单上方显示低一档价格的工时费预估。
- **导航与预填**：定位游戏市场、制作或强化页面并预填参数，最终购买、出售、制作和强化由玩家点击确认。
- **精简界面与使用说明**：规则说明集中在「设置 → 帮助」；列表通过表头排序，单件强化路线省略重复的数量标记。
- **经验与本地备份**：预估强化及制造经验，支持设置、分区和计划的本地备份。

期望消耗、工时费和利润是估算，不保证实际收益或成交价格。没有逐笔价格与时间的数据不会显示为真实成交记录。插件不会自动购买、出售、制作或强化，不读取登录凭据，不上传游戏数据。计划、设置与已保存记录留在本地。

## 安装与活跃统计及隐私

强化助手的安装与活跃统计默认开启，可在游戏内「强化助手 → 设置与备份 → 安装与活跃统计」查看说明并随时关闭，不影响插件功能；升级保留已经保存的关闭选择。

- 开启时仅向柆雨的统计服务发送插件标识、版本和随机安装标识的 SHA-256 摘要，用于统计安装数与每日活跃安装数，不统计游戏内操作。
- 不使用硬件指纹，不发送账号、角色、聊天、资产、交易或 Cookie。安装标识仅保存在该脚本的 Tampermonkey 存储中；摘要用于识别同一安装。请求通过 HTTPS 发送。
- **关闭时仍会尝试发送一次仅含插件标识和版本的关闭事件**，不含安装标识或其摘要，失败不重试；之后不再上报，已有历史保留。关闭事件只统计操作次数。

完整说明与源码见 [GitHub 项目](https://github.com/LaYuDr/mwi-layu-enhancement)。
